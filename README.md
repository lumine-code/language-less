# language-less

Less language support.

## Features

- **Grammars**: provides TextMate grammars derived from [atom/language-less](https://github.com/atom/language-less).
- **Syntax highlighting**: full grammar coverage for Less files.

## Installation

To install `language-less` search for _language-less_ in the Install pane of the Lumine settings or run `lumine --install lumine-code/language-less`.
